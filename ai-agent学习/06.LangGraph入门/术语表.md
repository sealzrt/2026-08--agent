## 2. 错误速查表

按报错文本找答案，每一行都对应教程里的"调试与排查"：

| 报错（关键词） | 含义 | 排查方向 | 章节 |
|---|---|---|---|
| `ModuleNotFoundError: No module named 'langgraph'` | 依赖没装 / 环境不对 | `pip install langgraph` + 激活虚拟环境 | 02, 03 |
| `ModuleNotFoundError: No module named 'app'` | 运行方式不对 | 在项目根目录用 `python -m app.xxx` | 14 |
| `KeyError: 'xxx'` | 读取了状态里没有的字段 | 初始状态与 `ResearchState` 对齐（不自动补默认值） | 02, 04 |
| `AttributeError: 'StateGraph' object has no attribute 'invoke'` | 忘了 `compile()` | 先 `graph = builder.compile()` | 03 |
| `ValueError: ... not in the graph` | `add_edge` 引用了未注册节点 | 核对 `add_node` 的节点名拼写 | 03 |
| `ImportError: Install grandalf` | `print_ascii()` 缺依赖 | 用 `graph.get_graph().draw_mermaid()` 或 `pip install grandalf` | 03 |
| `InvalidUpdateError`（路由标签不在映射表） | 路由函数返回了 `path_map` 外的标签 | `Literal` 标注 + 逐字核对标签 | 06 |
| `RuntimeError: 未设置 OPENAI_API_KEY` | 缺模型密钥 | `.env` 配置 + `load_dotenv()` | 08 |
| `json.JSONDecodeError` | 模型输出不是合法 JSON | 开 JSON mode + 解析失败兜底；必要时再加清洗 | 08 |
| `GraphRecursionError` | 循环没有终止条件 | 业务上限 + `recursion_limit` 双保险 | 09 |
| `KeyError`（新 thread 缺字段） | 该 thread 没有历史 checkpoint | 首次调用传全必填字段 | 10 |
| 中断后无法恢复 | 没挂 checkpointer / `thread_id` 不一致 | 两次调用用同一 `thread_id` | 11 |
| 副作用执行了两次 | 副作用放在 `interrupt()` 之前 | 移到之后，或保证幂等 | 11 |
| `stream_events` 报版本错误 | 忘了传 `version="v3"` | `stream_events(input, config, version="v3")` | 12 |

## 3. 易混概念对照

这几组概念是读者最常搞混的，一组一张表：

**业务循环限制 vs `recursion_limit`**

| | 业务循环限制 | `recursion_limit` |
|---|---|---|
| 谁负责 | 你的业务代码 | LangGraph 运行时 |
| 解决 | "什么时候应该停" | "代码写错时别无限跑" |
| 配置位置 | 状态字段（`max_iterations`） | config 顶层键 |

**checkpointer vs store**

| | checkpointer | store |
|---|---|---|
| 保存 | 线程级短期执行状态 | 跨线程长期记忆 |
| 生命周期 | 任务结束即可清理 | 长期保留 |

**`thread_id` vs `recursion_limit` 的位置**

| | 位置 | 用途 |
|---|---|---|
| `thread_id` | `config["configurable"]["thread_id"]` | 会话标识 |
| `recursion_limit` | `config["recursion_limit"]` | 运行时步数上限 |

**`stream()` vs `stream_events()`**

| | `stream()` | `stream_events(version="v3")` |
|---|---|---|
| 输出 | 图执行的状态 / 节点更新 | 类型化事件流 |
| 首选 | 后端调试 | 前端 / 观测系统 |

**失败重试 vs 业务循环**

| | 失败重试 | 业务循环 |
|---|---|---|
| 触发 | 瞬时故障 | 质量不达标 |
| 目的 | 同一次操作成功 | 补充数据后重新决策 |
| 位置 | 工具内部 | 图的边 |
