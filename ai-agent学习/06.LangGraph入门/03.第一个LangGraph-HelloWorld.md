# 03. 第一个 LangGraph Hello World

## 本章目标

- 安装并导入 LangGraph。
- 创建一个最小 `StateGraph`。
- 定义一个节点并连接 `START` 和 `END`。
- 使用 `invoke()` 执行图。

## 为什么需要这一章

前一章的代码只是普通函数。它能跑，但流程结构没有显式表达。LangGraph 会把“执行步骤”和“流程连接”拆开，让代码更接近流程图。

## 核心概念

### StateGraph

`StateGraph` 是构建有状态图工作流的主要入口。你需要告诉它状态结构是什么。

### Node

节点是一个 Python 函数。它接收当前状态，返回要更新的字段。

### START 和 END

`START` 是虚拟起点，`END` 是虚拟终点。它们不是业务节点，只用于描述图的边界。

### compile 和 invoke

`compile()` 会把图编译成可执行对象。`invoke()` 会执行一次图。

## 最小代码示例

安装依赖：

```powershell
pip install langgraph
```

创建文件 `03_first_graph.py`：

```python
from typing import TypedDict

from langgraph.graph import END, START, StateGraph


class ResearchState(TypedDict):
    topic: str
    summary: str


def generate_summary(state: ResearchState) -> dict[str, str]:
    return {
        "summary": f"这是关于《{state['topic']}》的 LangGraph 入门总结。"
    }


builder = StateGraph(ResearchState)
builder.add_node("generate_summary", generate_summary)
builder.add_edge(START, "generate_summary")
builder.add_edge("generate_summary", END)

graph = builder.compile()


if __name__ == "__main__":
    result = graph.invoke({
        "topic": "LangGraph 适合做什么",
        "summary": "",
    })
    print(result)
```

## 贯穿项目改造

现在项目从普通函数变成了单节点图：

```text
START -> generate_summary -> END
```

这还没有体现 LangGraph 的全部价值，但已经完成了关键转换：

- 业务步骤变成节点。
- 流程顺序变成边。
- 上下文变成状态。

## 代码运行方式

```powershell
python 03_first_graph.py
```

预期输出类似：

```text
{'topic': 'LangGraph 适合做什么', 'summary': '这是关于《LangGraph 适合做什么》的 LangGraph 入门总结。'}
```

## 常见错误

- 忘记 `compile()`：没有编译就不能执行图。
- 节点返回完整状态而不是局部更新：可以返回完整状态，但入门阶段建议只返回变化字段。
- `START` 和 `END` 拼错：它们应从 `langgraph.graph` 导入。
