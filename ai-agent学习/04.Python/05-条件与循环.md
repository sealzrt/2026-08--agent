## 5.1 条件判断 `if/elif/else`

### 5.1.1 基础形式

```python
age = int(input("你的年龄："))

if age >= 18:
    print("成年人，可以饮酒（在中国）")
else:
    print("未成年人，不能饮酒")
```

**语法要点**：

- `if` 后面跟**条件表达式**，以冒号 `:` 结尾
- 缩进（通常 4 个空格）表示"这一段属于上面的 if"
- **没有大括号**——Python 用缩进代替 `{}`

> ⚠️ **踩坑**：混用 Tab 和空格会报 `IndentationError`。统一用 4 空格（大多数编辑器默认就是）。

### 5.1.2 多分支 `elif`

```python
score = int(input("分数（0-100）："))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"等级：{grade}")
```

- `elif` = "else if" 的缩写
- 多个 elif 按顺序**依次判断**，命中第一个就停止——所以**顺序很重要**：要把"最严格"的条件放前面

### 5.1.3 真值测试（truthiness）

`if` 不要求条件必须是布尔值，任何对象都可以当条件：

```python
name = input("姓名：")
if name:                     # 非空字符串为 True
    print(f"你好，{name}")
else:
    print("你没输入名字")

items = []
if not items:                # 空列表为 False
    print("购物车是空的")
```

### 5.1.4 三元表达式

```python
age = 20
status = "成年" if age >= 18 else "未成年"
```

等价于：

```python
if age >= 18:
    status = "成年"
else:
    status = "未成年"
```

适合简单判断，复杂的还是用完整 `if/else`。

### 5.1.5 `match-case`（Python 3.10+）

类似其他语言的 switch，但功能更强（模式匹配）：

```python
command = input("命令：").lower()

match command:
    case "start" | "run":
        print("启动程序")
    case "stop" | "quit":
        print("退出程序")
    case "help":
        print("帮助信息")
    case _:                          # 默认分支
        print("未知命令")
```

## 5.2 `for` 循环：遍历可迭代对象

```python
fruits = ["苹果", "香蕉", "橙子"]
for fruit in fruits:
    print(f"我喜欢吃{fruit}")
```

📖 **可迭代对象**（iterable）：能被 `for` 遍历的东西——字符串、列表、元组、字典、集合、`range()`、文件对象等。

### 5.2.1 `range()` —— 生成数字序列

```python
for i in range(5):             # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 8):          # 2, 3, 4, 5, 6, 7
    print(i)

for i in range(0, 10, 2):      # 0, 2, 4, 6, 8 （步长 2）
    print(i)

for i in range(10, 0, -1):     # 10, 9, 8, ... 1 （倒序）
    print(i)
```

### 5.2.2 用 `enumerate()` 拿索引

```python
fruits = ["苹果", "香蕉", "橙子"]
for i, fruit in enumerate(fruits):
    print(f"{i+1}. {fruit}")
# 输出：
# 1. 苹果
# 2. 香蕉
# 3. 橙子
```

💡 **经验**：不要写 `for i in range(len(fruits)): fruits[i]`，用 `enumerate()` 更 Pythonic。

### 5.2.3 用 `zip()` 并行遍历多个序列

```python
names = ["小明", "小红", "小刚"]
scores = [92, 85, 78]

for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

### 5.2.4 遍历字典

```python
person = {"name": "小明", "age": 25, "city": "北京"}

for k in person:                         # 默认遍历键
    print(k)

for k, v in person.items():              # 同时遍历键和值
    print(f"{k}: {v}")

for v in person.values():                # 只遍历值
    print(v)
```

## 5.3 `while` 循环：条件满足就重复

```python
count = 0
while count < 5:
    print(count)
    count += 1         # 别忘了更新条件，否则死循环
```

### 5.3.1 典型用法：让用户一直输入，直到合法

```python
while True:
    try:
        age = int(input("请输入年龄："))
        if age < 0:
            print("年龄不能为负数，重试")
            continue
        break
    except ValueError:
        print("请输入数字")

print(f"年龄已记录：{age}")
```

## 5.4 `break` / `continue` / `else`

### 5.4.1 `break`：立刻退出整个循环

```python
for i in range(10):
    if i == 5:
        break
    print(i)
# 输出：0 1 2 3 4
```

### 5.4.2 `continue`：跳过本次，继续下一次

```python
for i in range(10):
    if i % 2 == 0:
        continue
    print(i)
# 输出：1 3 5 7 9
```

### 5.4.3 循环 `else`（Python 独有）

```python
for n in range(2, 10):
    for x in range(2, n):
        if n % x == 0:
            print(f"{n} = {x} × {n//x}")
            break
    else:
        # 只有循环"正常结束"（没被 break 打断）才执行
        print(f"{n} 是质数")
```

📖 **循环 else**：如果循环因 `break` 提前退出，else 不执行；如果循环自然跑完，else 执行。典型用途：**查找 + "未找到"提示**。

> 💡 **经验**：这个语法容易让人困惑，如果不确定要不要用，就用一个布尔标志变量代替。

## 5.5 嵌套与综合例子

### 5.5.1 九九乘法表

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j:2d}", end="  ")
    print()   # 换行
```

### 5.5.2 猜数字游戏

```python
import random

target = random.randint(1, 100)
tries = 0

while True:
    guess = int(input("猜一个 1-100 之间的数："))
    tries += 1

    if guess < target:
        print("太小了")
    elif guess > target:
        print("太大了")
    else:
        print(f"✅ 正确！你用了 {tries} 次猜中")
        break
```

## ⚠️ 本章踩坑提醒

1. **忘写冒号**：`if x > 0` 后面必须有 `:`
2. **缩进不一致**：混用 Tab 和空格会报错；统一用 4 空格
3. **死循环**：`while` 里忘了更新条件变量——按 `Ctrl+C` 终止
4. **`==` 写成 `=`**：`if x = 5:` 报 `SyntaxError`
5. **多个 elif 顺序**：`score >= 80` 必须放在 `score >= 60` 前面，否则 85 分会被判成 D
6. **修改正在遍历的列表**：`for item in lst: lst.remove(item)` 会漏删——用 `lst.copy()` 或列表推导
