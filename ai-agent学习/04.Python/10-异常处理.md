## 本章目标

读完本章后，你将能够：

1. 用 `try/except/else/finally` 处理程序错误
2. 识别常见异常类型并精确捕获

4. 定义自己的异常类
5. 知道什么时候该捕获、什么时候该让异常往上抛

> 📖 **异常**（Exception）：程序运行中遇到的"意外情况"——文件不存在、除零、类型不对、网络超时……Python 用异常对象"报信"，没人接就崩溃（打印 traceback 退出）。

## 10.1 异常长什么样

```python
>>> 1 / 0
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ZeroDivisionError: division by zero
```

**Traceback**（回溯）：从"出错地点"一路往上追到"入口"的调用链——调试时从最后一行往前看：最后一行是错误类型和消息，倒数几行是出错的具体位置。

## 10.2 `try/except`：捕获异常

### 10.2.1 基本用法

```python
try:
    num = int(input("请输入数字："))
    result = 10 / num
    print("结果：", result)
except ValueError:
    print("你输入的不是数字")
except ZeroDivisionError:
    print("不能除以 0")
```

- 多个 `except` 可以按类型分别处理
- 一旦某个 `except` 命中，剩下的都不会执行

### 10.2.2 捕获多个类型

```python
try:
    x = int("abc")
except (ValueError, TypeError) as e:
    print(f"出错了：{e}")
```

`as e` 把异常对象绑定到变量 `e`，可以打印错误详情。

### 10.2.3 捕获所有（慎用）

```python
try:
    risky_code()
except Exception as e:
    print(f"发生错误：{e}")
```

> ⚠️ **不要用裸 `except:`**（什么都不写）——它连 `Ctrl+C` 中断、系统退出都抓，调试时是噩梦。至少用 `except Exception:`。

## 10.3 `else` 和 `finally`

```python
try:
    f = open("data.txt", encoding="utf-8")
    data = f.read()
except FileNotFoundError:
    print("文件不存在")
else:
    # 只有 try 块没有抛异常时才执行
    print(f"读到 {len(data)} 个字符")
finally:
    # 无论是否异常，都会执行
    print("清理工作")
    try:
        f.close()
    except NameError:
        pass
```

- **`else`**：成功时才跑——让 `try` 块保持"最小化风险代码"
- **`finally`**：永远跑——用于关闭文件、释放资源等"善后"

💡 **经验**：能用 `with` 的场景不要用 `finally` 手动关闭，`with` 更简洁。

## 10.5 主动抛出异常 `raise`

```python
def set_age(age):
    if age < 0 or age > 150:
        raise ValueError(f"年龄 {age} 不合理")
    return age

set_age(200)
# ValueError: 年龄 200 不合理
```

### 10.5.1 重新抛出

```python
try:
    process()
except ValueError as e:
    logger.error(f"process 出错：{e}")
    raise        # 不传参数，把原异常继续往上抛
```

### 10.5.2 `raise ... from ...`（异常链）

```python
try:
    db.query()
except DatabaseError as e:
    raise RuntimeError("数据库查询失败") from e
```

保留原始异常的上下文，traceback 里能看到完整因果。

## 10.6 自定义异常

```python
class InvalidAgeError(Exception):
    def __init__(self, age, message="年龄必须在 0-150 之间"):
        self.age = age
        self.message = message
        super().__init__(f"{message}：{age}")

def set_age(age):
    if not 0 <= age <= 150:
        raise InvalidAgeError(age)
    return age
```

💡 **经验**：自定义异常让调用方可以**精准捕获**你库里的特定错误：

```python
try:
    set_age(200)
except InvalidAgeError as e:
    print(f"无效年龄：{e.age}")
```

## 10.7 最佳实践

### 10.7.1 EAFP vs LBYL

📖 **EAFP**（Easier to Ask Forgiveness than Permission）：先做再说，错了就捕获——Python 风格。

📖 **LBYL**（Look Before You Leap）：先检查再做——C/Java 风格。

```python
# LBYL
if key in my_dict:
    value = my_dict[key]
else:
    value = default

# EAFP（推荐）
try:
    value = my_dict[key]
except KeyError:
    value = default

# 更 Pythonic
value = my_dict.get(key, default)
```

### 10.7.2 别吞掉异常

```python
# ❌ 坏习惯：吞掉异常
try:
    risky()
except Exception:
    pass       # 出错时默默跳过，调试时找不到问题

# ✅ 好习惯：至少记录
try:
    risky()
except Exception as e:
    logger.exception(f"risky 失败：{e}")   # exception 自动记 traceback
```

### 10.7.3 精确捕获

```python
# ❌ 太宽
try:
    data = json.loads(text)
except Exception as e:
    print(f"解析失败：{e}")

# ✅ 精确
try:
    data = json.loads(text)
except json.JSONDecodeError as e:
    print(f"JSON 格式错误：第 {e.lineno} 行第 {e.colno} 列")
```

## 10.8 综合例子：健壮的整数输入

```python
def read_int(prompt, min_val=None, max_val=None):
    while True:
        try:
            s = input(prompt)
            n = int(s)
            if min_val is not None and n < min_val:
                print(f"不能小于 {min_val}")
                continue
            if max_val is not None and n > max_val:
                print(f"不能大于 {max_val}")
                continue
            return n
        except ValueError:
            print("请输入整数")

age = read_int("年龄：", min_val=0, max_val=150)
print(f"已记录：{age}")
```

## ⚠️ 本章踩坑提醒

1. **裸 `except:`**：永远不要用，至少写 `except Exception:`
2. **`except Exception as e` 里 `print(e)` 不记录 traceback**：要记录完整栈用 `logger.exception()` 或 `traceback.print_exc()`
3. **吞掉异常**：`except: pass` 是 debug 地狱
4. **捕获顺序**：子类异常要放在父类异常前面（`FileNotFoundError` 在 `OSError` 前）
5. **`finally` 里 return**：会覆盖 `try` 里的 return，非常迷惑，不要用
