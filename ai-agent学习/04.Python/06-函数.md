## 本章目标

读完本章后，你将能够：

1. 定义并调用函数（`def`）
2. 理解参数传递（位置参数、关键字参数、默认值、可变参数）
3. 掌握 `return` 和多返回值

5. 理解作用域（局部/全局）和闭包
6. 用 `lambda` 写小型匿名函数

> 📖 **函数**：一段可复用的、有名字的代码块——你可以把它想成"打包好的工具"：给它输入（参数），它给你输出（返回值）。`print()`、`len()`、`input()` 都是内置函数。

## 6.1 定义和调用函数

```python
def greet(name):
    """给某人打招呼"""
    return f"你好，{name}！"

msg = greet("小明")
print(msg)        # 你好，小明！
```

**结构**：

```
def 函数名(参数列表):
    """docstring"""
    函数体
    return 返回值
```

- 📖 **docstring**：函数第一行的三引号字符串，是给函数写的"说明书"，`help(greet)` 可以调用
- 如果函数没有 `return`，默认返回 `None`

### 6.1.1 查看函数帮助

```python
help(greet)
# Help on function greet in module __main__:
#
# greet(name)
#     给某人打招呼
```

💡 **经验**：每次写函数都顺手写 docstring，半年后你会感谢现在的自己。

## 6.2 参数传递的四种方式

### 6.2.1 位置参数（按顺序）

```python
def subtract(a, b):
    return a - b

subtract(10, 3)    # 7
```

### 6.2.2 关键字参数（按名字）

```python
subtract(b=3, a=10)     # 7  —— 顺序无所谓
```

### 6.2.3 默认参数

```python
def power(base, exp=2):
    return base ** exp

power(5)       # 25
power(5, 3)    # 125
```

> ⚠️ **踩坑**：**默认参数不要用可变对象**！

```python
def add_item(item, lst=[]):        # ❌ 危险写法
    lst.append(item)
    return lst

print(add_item(1))    # [1]
print(add_item(2))    # [1, 2]   —— 不是 [2]！默认值被复用了
```

正确写法：

```python
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

### 6.2.4 可变参数

**`*args`**：收集任意个位置参数，变成一个元组

```python
def total(*numbers):
    s = 0
    for n in numbers:
        s += n
    return s

total(1, 2, 3, 4)      # 10
```

**`**kwargs`**：收集任意个关键字参数，变成一个字典

```python
def show_info(**info):
    for k, v in info.items():
        print(f"{k}: {v}")

show_info(name="小明", age=25, city="北京")
```

**混合使用**：

```python
def f(a, b, *args, key=None, **kwargs):
    pass

f(1, 2, 3, 4, 5, key="x", extra="y")
# a=1, b=2, args=(3,4,5), key="x", kwargs={"extra":"y"}
```

**顺序固定**：位置参数 → `*args` → 关键字参数 → `**kwargs`。

### 6.2.5 强制关键字参数（Python 3 特性）

```python
def connect(host, port, *, timeout=30, retry=3):
    pass

connect("localhost", 8080, timeout=10)     # OK
connect("localhost", 8080, 10)             # ❌ timeout 必须用关键字
```

`*` 后面的参数只能用关键字传，避免"参数到底代表啥"的歧义。

## 6.3 返回值

### 6.3.1 单值返回

```python
def square(x):
    return x * x
```

### 6.3.2 多返回值（实际返回元组）

```python
def divide(a, b):
    return a // b, a % b

q, r = divide(17, 5)
print(q, r)     # 3 2
```

### 6.3.3 提前返回

```python
def is_even(n):
    if n % 2 == 0:
        return True
    return False
```

等价于 `return n % 2 == 0`。

## 6.4 作用域

```python
x = 10                # 全局变量

def f():
    y = 5             # 局部变量
    print(x + y)      # 可以读全局变量

f()
print(y)              # ❌ NameError：y 在函数外不存在
```

### 6.4.1 `global` 声明修改全局变量

```python
count = 0

def increment():
    global count
    count += 1

increment()
print(count)       # 1
```

> ⚠️ **踩坑**：少用 `global`！会让代码难以推理。优先用函数参数和返回值。

### 6.4.2 `nonlocal` 嵌套函数修改外层变量

```python
def make_counter():
    n = 0
    def counter():
        nonlocal n
        n += 1
        return n
    return counter

c = make_counter()
print(c())    # 1
print(c())    # 2
print(c())    # 3
```

📖 **闭包**（closure）：内部函数"记住"了外层函数的变量，哪怕外层函数已经返回。这是函数式编程和装饰器的基础（第 12 章会再讲）。

## 6.5 `lambda`：一行式匿名函数

```python
square = lambda x: x * x
print(square(5))     # 25
```

等价于：

```python
def square(x):
    return x * x
```

`lambda` 适合**短小、一次性**的函数，典型场景：

```python
people = [("Alice", 30), ("Bob", 25), ("Charlie", 35)]
people.sort(key=lambda p: p[1])      # 按年龄排序
print(people)
# [('Bob', 25), ('Alice', 30), ('Charlie', 35)]
```

## 6.6 函数是一等公民

函数可以赋给变量、当参数传、当返回值：

```python
def apply(f, x):
    return f(x)

def double(n): return n * 2

apply(double, 5)     # 10
apply(lambda n: n+1, 5)   # 6
```

### 6.6.1 高阶函数 `map` / `filter`

```python
nums = [1, 2, 3, 4, 5]
list(map(lambda x: x**2, nums))           # [1, 4, 9, 16, 25]
list(filter(lambda x: x % 2 == 0, nums))  # [2, 4]
```

> 💡 **经验**：更 Pythonic 的写法是列表推导（第 7 章）：`[x**2 for x in nums]`

## 6.7 类型注解（Python 3.5+）

```python
def add(a: int, b: int) -> int:
    return a + b
```

注解只是**提示**，Python 不强制检查，但可以被 mypy 等工具静态分析，也能被 IDE 用来做补全。

```python
def greet(name: str, age: int = 0) -> str:
    return f"{name} 今年 {age} 岁"
```

💡 **经验**：项目越大越要写类型注解，相当于给函数加"使用说明书"。

## ⚠️ 本章踩坑提醒

1. **默认参数用可变对象**：`def f(x=[])` 是经典 bug，用 `None` 替代
2. **忘写 `return`**：函数返回 `None`，后续用到会报 `TypeError`
3. **函数名遮蔽内置**：别把函数叫 `print`、`list`、`max`
4. **可变参数顺序**：`*args` 必须在位置参数后、`**kwargs` 前
5. **`global` 滥用**：会让代码难读难测，能用参数和返回值就不用 global
