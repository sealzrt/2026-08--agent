## 8.1 字符串常用方法

### 8.1.1 大小写

```python
s = "Hello, World!"
s.lower()        # 'hello, world!'
s.upper()        # 'HELLO, WORLD!'
s.title()        # 'Hello, World!'
s.capitalize()   # 'Hello, world!'
s.swapcase()     # 'hELLO, wORLD!'
s.casefold()     # 比 lower 更激进，适合跨语言比较
```

### 8.1.2 查找与统计

```python
s = "Python is Pythonic and Python is great"
s.find("Python")        # 0  —— 第一次出现的位置（找不到返回 -1）
s.index("Python")       # 0  —— 同上，但找不到会抛 ValueError
s.rfind("Python")       # 25 —— 最后一次出现
s.count("Python")       # 3  —— 出现次数
s.startswith("Py")      # True
s.endswith("great")     # True
```

### 8.1.3 分割与连接

```python
"a,b,c,d".split(",")              # ['a', 'b', 'c', 'd']
"hello world".split()              # ['hello', 'world']  默认按空白分割
"a\nb\nc".splitlines()             # ['a', 'b', 'c']

",".join(["a", "b", "c"])          # "a,b,c"
" - ".join(["2026", "07", "29"])   # "2026 - 07 - 29"
```

💡 **经验**：用 `"".join(list)` 拼接大量字符串比 `+` 循环**快几十倍**——因为 `+` 每次都复制一次字符串。

### 8.1.4 替换与去除

```python
"hello".replace("l", "L")    # 'heLLo'  （全部替换）
"  hello  ".strip()          # 'hello'   两端去空白
"  hello  ".lstrip()         # 'hello  '
"  hello  ".rstrip()         # '  hello'
"###hello###".strip("#")     # 'hello'
"hello".ljust(10, "*")       # 'hello*****'  左对齐补 *
"hello".rjust(10, "*")       # '*****hello'
"hello".center(10, "*")      # '**hello***'
"42".zfill(5)                # '00042'
```

### 8.1.5 判断类方法

```python
"abc".isalpha()         # True （全是字母）
"123".isdigit()         # True （全是数字）
"abc123".isalnum()      # True （字母+数字）
"   ".isspace()         # True （全是空白）
"Hello".istitle()       # True （首字母大写）
"lower".islower()       # True
"UPPER".isupper()       # True
```

## 8.2 字符串切片再深入

```python
s = "Python"
s[0]        # 'P'
s[-1]       # 'n'
s[2:5]      # 'tho'
s[:3]       # 'Pyt'
s[3:]       # 'hon'
s[::2]      # 'Pto'        步长 2
s[::-1]     # 'nohtyP'     反转
```

**经典应用**：判断回文

```python
def is_palindrome(s):
    return s == s[::-1]

is_palindrome("racecar")    # True
is_palindrome("hello")      # False
```

## 8.3 编码问题：str 和 bytes

> 📖 **Unicode**：一套给所有字符（中文、英文、emoji……）都编唯一号码的国际标准。Python 的 `str` 在内存里就是 Unicode。
>
> 📖 **bytes**：字节串——Unicode 字符串的"二进制表示"，用于存储和传输。

```python
text = "你好"
b = text.encode("utf-8")     # str → bytes
print(b)                      # b'\xe4\xbd\xa0\xe5\xa5\xbd'

b.decode("utf-8")            # bytes → str
# '你好'
```

### 为什么会有乱码？

```python
"你好".encode("utf-8").decode("gbk")
# ❌ UnicodeDecodeError
```

用 UTF-8 编码的 bytes，必须用 UTF-8 解码——不一致就乱码。Windows 中文终端默认 GBK，是乱码的重灾区。

💡 **经验**：写文件、网络请求、读二进制数据时，**永远显式指定 `encoding="utf-8"`**。

## 8.4 正则表达式：字符串的瑞士军刀

> 📖 **正则表达式**（regex）：一套描述"字符串模式"的语言——用少量符号表达"像 XXX 的字符串"。Python 里用 `re` 模块支持。

### 8.4.1 核心元字符

| 元字符 | 含义 | 示例 |
| --- | --- | --- |
| `.` | 任意单字符（除换行） | `h.t` 匹配 "hat" "hot" |
| `\d` `\D` | 数字 / 非数字 | `\d+` 匹配连续数字 |
| `\w` `\W` | 字母数字下划线 / 其他 | `\w+` 匹配单词 |
| `\s` `\S` | 空白 / 非空白 | `\s+` 匹配连续空白 |
| `^` `$` | 字符串开头 / 结尾 | `^Hello` 必须以 Hello 开头 |
| `*` `+` `?` | 0 次或多次 / 1+ / 0-1 | `colou?r` 匹配 color 和 colour |
| `{n}` `{n,m}` | 恰好 n 次 / n 到 m 次 | `\d{4}` 匹配 4 位数字 |
| `[abc]` | 字符类 | `[aeiou]` 匹配元音 |
| `[^abc]` | 取反字符类 | `[^0-9]` 匹配非数字 |
| `( )` | 分组 | `(\w+)@(\w+)` 分两部分 |

### 8.4.2 `re` 模块常用函数

```python
import re

# 查找
re.findall(r"\d+", "订单号 12345，金额 99.9")     # ['12345', '99', '9']

# 搜索（返回第一个匹配）
m = re.search(r"(\d+)", "订单号 12345")
m.group(0)        # '12345'
m.group(1)        # '12345' （第一个分组）

# 匹配（必须从开头开始）
re.match(r"Hello", "Hello World")      # 匹配
re.match(r"World", "Hello World")      # None

# 替换
re.sub(r"\d+", "XXX", "A1B22C333")    # 'AXXBXXXCXXX'

# 分割
re.split(r"\s+", "a   b\tc\nd")       # ['a', 'b', 'c', 'd']
```

### 8.4.3 r-string 与正则

正则里 `\d`、`\b` 等符号多，如果不用 r-string，每个 `\` 都要写 `\\`：

```python
re.findall("\\d+", text)   # 难读
re.findall(r"\d+", text)   # 推荐
```

### 8.4.4 常用场景

**提取邮箱**：

```python
text = "联系我：alice@example.com 或 bob.123@test.org"
re.findall(r"[\w.]+@[\w.]+\.\w+", text)
# ['alice@example.com', 'bob.123@test.org']
```

**提取手机号（简化）**：

```python
text = "电话 13812345678 和 18600001111"
re.findall(r"1[3-9]\d{9}", text)
# ['13812345678', '18600001111']
```

**拆分复杂字符串**：

```python
re.split(r"[,;\|]", "a,b;c|d")    # ['a', 'b', 'c', 'd']
```

## 8.5 什么时候用正则？

| 场景 | 推荐方案 |
| --- | --- |
| 固定字符串查找/替换 | `str.find()` / `str.replace()` |
| 按单一分隔符切分 | `str.split()` |
| 模式匹配（如邮箱、手机号） | `re` |
| 复杂文本解析（HTML/XML） | `BeautifulSoup` / `lxml`（不要自己用正则） |

💡 **经验**：不要什么都用正则——简单任务用字符串方法更快、更可读。

## ⚠️ 本章踩坑提醒

1. **字符串不可变**：`s.replace(...)` 不会改 s，要重新赋值 `s = s.replace(...)`
2. **`split()` vs `split(" ")`**：前者按任意空白（含连续），后者按单个空格（会出现空字符串）
3. **编码一致**：`encode` 和 `decode` 的编码必须一致，否则乱码/报错
4. **正则里忘用 r-string**：`"\d"` 在 Python 里就是字母 `d`（Python 不识别 `\d` 转义），正则拿不到 `\d`
5. **`re.match` 必须从开头**：要在中间匹配用 `re.search`
