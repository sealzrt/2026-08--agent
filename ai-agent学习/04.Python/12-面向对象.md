## 本章目标

读完本章后，你将能够：

1. 理解"类"和"对象"的概念
2. 定义自己的类，包含属性、方法、构造函数
3. 用继承复用代码
4. 使用 `@property`、`@classmethod`、`@staticmethod`
5. 理解"魔法方法"（dunder methods）让对象更 Pythonic

> 📖 **类**（class）：对象的"蓝图"或"模板"。
> 📖 **对象**（object）/ **实例**（instance）：按蓝图造出来的"具体东西"。
> 类比：`Car` 是类（汽车的蓝图），你车库里那辆红色特斯拉是对象（Car 类的一个实例）。

## 12.1 第一个类

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        return f"{self.name}: 汪汪！"

    def info(self):
        return f"{self.name}，{self.age} 岁"

# 创建实例
buddy = Dog("Buddy", 3)
print(buddy.bark())       # Buddy: 汪汪！
print(buddy.info())       # Buddy，3 岁
```

**关键点**：

- 📖 **`__init__`**：构造方法（初始化），创建实例时自动调用
- 📖 **`self`**：方法第一个参数，代表"当前实例"——调用时不用传，Python 自动传
- 📖 **属性**（attribute）：`self.name`、`self.age`——实例携带的数据
- 📖 **方法**（method）：`bark()`、`info()`——实例能做的动作

## 12.2 属性与方法

### 12.2.1 实例属性 vs 类属性

```python
class Dog:
    species = "犬科"              # 类属性：所有实例共享

    def __init__(self, name):
        self.name = name          # 实例属性：每个实例独有

d1 = Dog("Buddy")
d2 = Dog("Max")
d1.species     # "犬科"
d2.species     # "犬科"
Dog.species    # "犬科"           可以直接通过类访问
```

⚠️ **类属性被实例修改会变成实例属性**：

```python
d1.species = "猫科"            # 给 d1 创建了一个新的实例属性
d1.species                     # "猫科"
d2.species                     # "犬科" —— d2 没变
Dog.species                    # "犬科" —— 类属性也没变
```

### 12.2.2 实例方法 / 类方法 / 静态方法

```python
class Circle:
    pi = 3.14159

    def __init__(self, radius):
        self.radius = radius

    # 实例方法：需要访问 self
    def area(self):
        return self.pi * self.radius ** 2

    # 类方法：需要访问类（不是实例）
    @classmethod
    def from_diameter(cls, diameter):
        return cls(diameter / 2)

    # 静态方法：和类/实例都无关，纯工具函数
    @staticmethod
    def is_valid_radius(r):
        return r >= 0

c1 = Circle(5)
c2 = Circle.from_diameter(10)    # 用类方法当"替代构造器"
Circle.is_valid_radius(-3)       # False
```

💡 **经验**：不确定用哪种时，默认用**实例方法**。

## 12.3 `@property`：把方法变成属性

```python
class Person:
    def __init__(self, first, last):
        self.first = first
        self.last = last

    @property
    def full_name(self):
        return f"{self.first} {self.last}"

    @full_name.setter
    def full_name(self, value):
        self.first, self.last = value.split()

p = Person("张", "三")
print(p.full_name)           # "张 三"    —— 像访问属性一样
p.full_name = "李 四"         # 触发 setter
print(p.first, p.last)       # 李 四
```

📖 **property**：让方法调用**不需要括号**，常用于：

- 计算型属性（如 `area`、`full_name`）
- 给属性加校验（setter 里验证）
- 向后兼容（把属性改成方法而不破坏调用方）

## 12.4 继承

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name} makes a sound"

class Dog(Animal):
    def speak(self):             # 重写父类方法
        return f"{self.name} 汪汪"

class Cat(Animal):
    def speak(self):
        return f"{self.name} 喵喵"

d = Dog("Buddy")
c = Cat("Kitty")
d.speak()     # "Buddy 汪汪"
c.speak()     # "Kitty 喵喵"

isinstance(d, Dog)       # True
isinstance(d, Animal)    # True —— 子类实例也是父类实例
```

### 12.4.1 调用父类方法 `super()`

```python
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)     # 调用父类 __init__
        self.breed = breed

    def speak(self):
        base = super().speak()     # 调用父类方法
        return base + " (汪汪)"
```

### 12.4.2 多重继承与 MRO

```python
class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass

D.__mro__
# (D, B, C, A, object) —— 方法解析顺序
```

💡 **经验**：多重继承容易出问题，能用组合就别用多重继承（后面会讲）。

## 12.5 魔法方法（dunder methods）

以双下划线开头结尾的特殊方法，让对象支持 Python 内置操作。

### 12.5.1 字符串表示

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        # 给开发者看的"精确表示"
        return f"Point({self.x}, {self.y})"

    def __str__(self):
        # 给最终用户看的"友好表示"
        return f"({self.x}, {self.y})"

p = Point(3, 4)
print(p)           # (3, 4)       调 __str__
repr(p)            # 'Point(3, 4)' 调 __repr__
```

### 12.5.2 让对象支持运算符

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

    def __abs__(self):
        return (self.x**2 + self.y**2) ** 0.5

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)      # Vector(4, 6)
print(abs(v2))       # 5.0
print(v1 == v2)      # False
```

### 12.5.3 让对象可迭代、可索引、可比较

| 方法 | 支持的操作 |
| --- | --- |
| `__len__(self)` | `len(obj)` |
| `__getitem__(self, key)` | `obj[key]` |
| `__setitem__(self, key, val)` | `obj[key] = val` |
| `__iter__(self)` | `for x in obj` |
| `__contains__(self, item)` | `item in obj` |
| `__lt__`, `__le__`, `__gt__`, `__ge__`, `__eq__`, `__ne__` | 比较运算符 |
| `__call__(self, ...)` | `obj(...)` 让实例像函数一样被调用 |
| `__enter__` / `__exit__` | `with obj:` 上下文管理 |

### 12.5.4 上下文管理器

```python
class Timer:
    def __enter__(self):
        import time
        self.start = time.time()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        import time
        self.elapsed = time.time() - self.start
        print(f"耗时：{self.elapsed:.3f} 秒")
        return False    # 不吞掉异常

with Timer():
    sum(range(10_000_000))
# 耗时：0.234 秒
```

## 12.6 dataclass（Python 3.7+）

当类主要是"数据容器"时，用 `@dataclass` 省掉大量模板代码：

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: float
    y: float
    label: str = "origin"

    def distance(self):
        return (self.x**2 + self.y**2) ** 0.5

p = Point(3, 4, "A")
print(p)             # Point(x=3, y=4, label='A')  —— 自动生成 __repr__
print(p.distance())  # 5.0
p2 = Point(3, 4, "A")
print(p == p2)       # True    —— 自动生成 __eq__
```

💡 **经验**：只要类的主要用途是"装数据"，就考虑 dataclass。

## 12.7 组合优于继承

```python
# 继承（紧耦合）
class ElectricCar(Car):
    def charge(self): ...

# 组合（松耦合）
class Battery:
    def charge(self): ...

class ElectricCar:
    def __init__(self):
        self.battery = Battery()    # 拥有，而不是继承
```

📖 **组合**：一个对象持有另一个对象（"has-a"）。
📖 **继承**：一个对象是另一个对象的子类（"is-a"）。

💡 **原则**：能用组合就别用继承——组合更灵活、更松耦合。

## 12.8 类型注解在类中的用法

```python
from typing import Optional, List

class User:
    def __init__(self, name: str, email: str, age: Optional[int] = None):
        self.name: str = name
        self.email: str = email
        self.age: Optional[int] = age
        self.tags: List[str] = []
```

## ⚠️ 本章踩坑提醒

1. **忘写 `self`**：方法第一个参数必须是 `self`，调用时 Python 自动传
2. **类属性被实例修改**：`obj.cls_attr = x` 会创建实例属性覆盖类属性
3. **`__str__` 和 `__repr__` 分不清**：`__repr__` 必须无歧义（开发者用），`__str__` 友好（用户用）
4. **继承层级太深**：超过 2-3 层就该反思设计，多用组合
5. **`super().__init__()` 漏写**：子类构造函数里不调父类构造，父类属性不会初始化
