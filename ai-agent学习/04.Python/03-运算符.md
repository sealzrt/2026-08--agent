## 3.1 算术运算符

| 运算符 | 含义 | 示例 | 结果 |
| --- | --- | --- | --- |
| `+` `-` `*` | 加减乘 | `3 + 4` | `7` |
| `/` | 真除（始终返回 float） | `7 / 2` | `3.5` |
| `//` | 整除（向下取整） | `7 // 2` | `3` |
| `%` | 取余 | `7 % 2` | `1` |
| `**` | 幂 | `2 ** 10` | `1024` |

```python
>>> 10 / 3
3.3333333333333335
>>> 10 // 3
3
>>> -7 // 3
-3             # 注意：向下取整，不是向零取整
>>> -7 / 3
-2.3333333333333335
```

> ⚠️ **踩坑**：`//` 是"向下取整"（floor），负数会往更小方向取。如果只想要"丢掉小数"，用 `int(-7/3)` = `-2`。

### `divmod()` 同时拿商和余

```python
>>> divmod(17, 5)
(3, 2)       # 商 3，余 2
```

💡 **经验**：要同时算"多少份"和"剩多少"（比如把秒换成分钟）时，用 `divmod()` 比两次除法效率高、语义更清楚。

```python
seconds = 3665
minutes, secs = divmod(seconds, 60)
hours, minutes = divmod(minutes, 60)
print(f"{hours}h {minutes}m {secs}s")   # 1h 1m 5s
```

## 3.2 比较运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `==` `!=` | 值相等/不等 | `3 == 3.0` → `True` |
| `>` `>=` `<` `<=` | 大于、大于等于、小于、小于等于 | `3 > 2` → `True` |

### 3.2.1 链式比较（Python 独有）

```python
>>> x = 5
>>> 1 < x < 10
True
>>> 1 < x > 2
True                 # 等价于 (1 < x) and (x > 2)
```

这在数学里很自然，在其他语言里通常要写 `1 < x and x < 10`。

### 3.2.2 `==` vs `is`（极易混淆）

```python
>>> a = [1, 2, 3]
>>> b = [1, 2, 3]
>>> a == b
True            # 值相等
>>> a is b
False           # 不是同一个对象

>>> c = a
>>> a is c
True            # c 和 a 指向同一个列表
```

- `==` 比较**值**（调用 `__eq__` 方法）
- `is` 比较**身份**（是否是同一个内存对象）

💡 **规则**：判断 `None` 时用 `is None`，判断值相等用 `==`。

## 3.3 逻辑运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `and` | 且 | `x > 0 and x < 10` |
| `or` | 或 | `x == 0 or x == 1` |
| `not` | 非 | `not is_valid` |

### 短路求值

```python
>>> True or 1/0
True              # 左边已经决定结果，右边不执行（避免除零）
>>> False and 1/0
False             # 同理
```

### `and` / `or` 的返回值不是布尔

```python
>>> 0 or 5
5
>>> "" or "default"
'default'
>>> 1 and 2
2
```

📖 **规则**：`and` 返回第一个"假值"或最后一个值；`or` 返回第一个"真值"或最后一个值。这经常被用来写"默认值"模式：

```python
name = user_input or "匿名用户"     # 如果 user_input 为空，用默认值
```

## 3.4 成员与身份运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `in` | 是否在某容器中 | `"a" in "apple"` → `True` |
| `not in` | 不在某容器中 | `3 not in [1, 2]` → `True` |
| `is` | 是否同一对象 | `a is None` |
| `is not` | 不是同一对象 | `a is not b` |

```python
fruits = ["apple", "banana", "orange"]
"apple" in fruits          # True
"grape" not in fruits      # True
```

## 3.5 位运算符（了解即可）

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `&` `\|` `^` `~` | 按位与/或/异或/取反 | `5 & 3` → `1` |
| `<<` `>>` | 左移、右移 | `1 << 3` → `8` |

大多数业务代码用不到，但写权限掩码、加密、网络编程时会用。

---

## 3.6 赋值运算符

| 运算符 | 等价 |
| --- | --- |
| `=` | 基本赋值 |
| `+=` `-=` `*=` `/=` | `a = a + b` 等 |
| `//=` `%=` `**=` | 整除/取余/幂赋值 |
| `&=` `\|=` `^=` `<<=` `>>=` | 位运算赋值 |

```python
x = 10
x += 5     # x = 15
x **= 2    # x = 225
```

## 3.7 优先级（从高到低）

| 优先级 | 运算符 |
| --- | --- |
| 最高 | `()` |
| ↓ | `**` |
| ↓ | `~` `+x` `-x`（一元） |
| ↓ | `*` `/` `//` `%` |
| ↓ | `+` `-` |
| ↓ | `<<` `>>` |
| ↓ | `&` |
| ↓ | `^` |
| ↓ | `\|` |
| ↓ | 比较运算符 `==` `!=` `<` `>` 等 |
| ↓ | `is` `is not` `in` `not in` |
| ↓ | `not` |
| ↓ | `and` |
| ↓ | `or` |
| 最低 | 赋值 `=` |

💡 **经验**：记不住就用括号 `()`。`(a or b) and c` 比 `a or b and c` 清楚一百倍。

## 3.8 表达式求值示例

```python
result = 3 + 4 * 2 ** 2 > 10 and not (5 == 5)
# 等价于：
# 3 + (4 * (2**2)) > 10 and not (5==5)
# (3 + 16) > 10 and not True
# 19 > 10 and False
# True and False
# False
```

## ⚠️ 本章踩坑提醒

1. **`/` 永远返回 float**：`4 / 2` 是 `2.0` 不是 `2`。想要整除用 `//`
2. **`==` 和 `is` 混用**：判断 None 必须用 `is`；判断值相等用 `==`
3. **`-7 // 3` 是 `-3` 不是 `-2`**：向下取整规则，负数时和直觉相反
4. **`0.1 + 0.2 != 0.3`**：浮点精度问题，比较浮点数用 `math.isclose()`
5. **`and` / `or` 返回的不是 bool**：注意短路求值会返回最后一个被求值的操作数
