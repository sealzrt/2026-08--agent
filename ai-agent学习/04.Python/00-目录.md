# Python 入门教程 · 总目录

> 定位：面向零基础读者的 **Python 实战入门系列**，目标不是把 Python 讲成"编程教科书"，而是把读者带到**能用 Python 干点真事**的程度——写脚本处理 Excel、批量操作文件、做数据清洗、调用 AI 接口，最终衔接到本仓库的 AI Agents 课程。
>
> 阅读方式：**从第 1 章按顺序读**，每章末尾有"踩坑提醒"和"动手练习"，建议边读边在本地敲一遍代码，不要跳着看。
>
> 配套：本目录与 `00.ai-agent/01-ai-agents-intro-zh-optimized.md`（微软 AI Agents 课程）放在同一个学习体系里；Python 入门完成后，可直接进入 AI Agents 课程实操。

## 章节编写原则

每章内容遵循同一套"五段式"结构：

1. **是什么**：一段话讲清本章主题，配生活化类比
2. **为什么**：解释这个特性解决了什么问题（不是罗列特性清单）
3. **怎么做**：可运行的代码 + 输出 + 逐行讲解
4. **踩坑提醒**：初学者最容易犯的错误、最容易漏的细节
5. **动手练习**：3~5 个由浅入深的小练习，答案在正文或下一节
