## 4.1 `print()` 的高级用法

### 4.1.1 默认行为

```python
>>> print("hello")
hello
>>> print(1, 2, 3)
1 2 3              # 多个参数默认用空格分隔
>>> print("a", "b", "c")
a b c
```

### 4.1.2 控制分隔符和结尾

```python
>>> print("2026", "07", "29", sep="-")
2026-07-29
>>> print("loading", end="... ")
loading... >>>     # end 默认是换行符 \n
```

### 4.1.3 打印到文件（重定向）

```python
with open("log.txt", "w", encoding="utf-8") as f:
    print("这是一行日志", file=f)
```

> ⚠️ **踩坑**：在 Windows 中文环境写文件，**一定要加 `encoding="utf-8"`**，否则默认 GBK 编码会导致后续读取乱码。

## 4.2 `input()`：让用户说话

```python
name = input("请输入你的名字：")
print(f"你好，{name}！")
```

- `input()` 返回的**永远是字符串**，哪怕用户输入的是数字
- 需要数字时，必须显式转换：`int(input(...))` 或 `float(input(...))`

### 4.2.1 完整小例子：简单计算器

```python
a = float(input("第一个数："))
b = float(input("第二个数："))
op = input("运算符（+ - * /）：")

if op == "+":
    print("结果：", a + b)
elif op == "-":
    print("结果：", a - b)
elif op == "*":
    print("结果：", a * b)
elif op == "/":
    print("结果：", a / b)
else:
    print("未知运算符")
```

> 💡 **经验**：真实项目里，用户输入永远不可信——必须做校验、处理异常（第 10 章会讲 try/except）。

## 4.3 f-string：Python 3.6+ 的主力格式化方式

> 📖 **f-string**：在字符串前加字母 `f`，里面的 `{变量名}` 会在运行时被替换成变量的值。

```python
name = "小明"
age = 25
print(f"{name} 今年 {age} 岁")        # 小明 今年 25 岁
print(f"明年 {name} 就 {age + 1} 了") # 可以放表达式
```

### 4.3.1 控制数字格式

```python
price = 19.99
quantity = 3
total = price * quantity

print(f"总价：{total}")             # 59.97
print(f"总价：{total:.2f}")         # 59.97 （固定 2 位小数）
print(f"总价：{total:,.2f}")        # 59.97 （带千分位）
print(f"总价：{total:>10,.2f}")     #      59.97 （右对齐，宽度 10）

big = 1234567890
print(f"{big:,}")                   # 1,234,567,890
print(f"{big:_}")                   # 1_234_567_890
```

### 4.3.2 百分比、科学计数、进制

```python
rate = 0.856
print(f"{rate:.2%}")        # 85.60%
print(f"{rate:.2e}")        # 8.56e-01

n = 255
print(f"{n:b} {n:o} {n:x}") # 11111111 377 ff （二进制/八进制/十六进制）
```

### 4.3.3 调试利器：`{var=}`

Python 3.8 引入：在 f-string 里写 `{var=}` 会打印变量名和值。

```python
x = 42
print(f"{x=}")       # x=42
print(f"{x*2=}")     # x*2=84
```

💡 **经验**：调试时比 `print("x =", x)` 少打一半字。

## 4.4 其他格式化方式（了解）

### 4.4.1 `str.format()`（f-string 之前的主流）

```python
"{} 今年 {} 岁".format("小明", 25)
"{name} 今年 {age} 岁".format(name="小明", age=25)
"{0} {1} {0}".format("hello", "world")  # hello world hello
```

老代码里常见，新项目优先用 f-string。

### 4.4.2 `%` 风格（C 风格，过时但不废弃）

```python
"姓名：%s，年龄：%d" % ("小明", 25)
```

基本不用了，但读老代码会遇到。

## 4.5 多行字符串与转义字符

### 4.5.1 三引号（`"""` 或 `'''`）

```python
poem = """静夜思
床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。"""
print(poem)
```

三引号字符串**会保留换行和缩进**，适合写多行文本或 SQL 模板。

### 4.5.2 转义字符

| 转义 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | Tab（制表符） |
| `\\` | 反斜杠本身 |
| `\'` `\"` | 单/双引号 |
| `\r` | 回车 |

```python
print("第一行\n第二行")
print("He said \"OK\"")
```

### 4.5.3 原始字符串 r-string

在字符串前加 `r`，所有转义字符都失效——**写正则表达式和 Windows 路径时必备**。

```python
print(r"C:\new\test")   # 不会把 \n 解释为换行
# 输出：C:\new\test
```

> ⚠️ **踩坑**：Windows 路径千万别写 `"C:\new\test"`——`\n` 会被当成换行。要么用 `r"C:\new\test"`，要么用 `pathlib.Path`（第 9 章）。

## 4.6 一个完整的小脚本

把下面保存为 `bmi.py`：

```python
# bmi.py —— 计算身体质量指数

name = input("请输入你的名字：")
height = float(input("身高（米，如 1.75）："))
weight = float(input("体重（千克，如 70）："))

bmi = weight / (height ** 2)

print(f"\n{'='*30}")
print(f"{name} 的 BMI 计算结果")
print(f"{'='*30}")
print(f"身高：{height:.2f} 米")
print(f"体重：{weight:.1f} 千克")
print(f"BMI ：{bmi:.2f}")

if bmi < 18.5:
    category = "偏瘦"
elif bmi < 24:
    category = "正常"
elif bmi < 28:
    category = "偏胖"
else:
    category = "肥胖"

print(f"评估：{category}")
```

运行示例：

```powershell
$ python bmi.py
请输入你的名字：小明
身高（米，如 1.75）：1.75
体重（千克，如 70）：70

==============================
小明 的 BMI 计算结果
==============================
身高：1.75 米
体重：70.0 千克
BMI ：22.86
评估：正常
```

这段代码综合运用了：`input` 取输入、`float()` 类型转换、f-string 格式化、字符串重复（`'='*30`）、if/elif/else（下一章细讲）。

## ⚠️ 本章踩坑提醒

1. **`input()` 永远返回字符串**：`age = input("年龄")` 拿到的是 `"25"` 不是 `25`，必须 `int()` 转换
2. **Windows 路径用 r-string**：`"C:\new\test"` 会被 `\n` 破坏，写 `r"C:\new\test"`
3. **写文件忘编码**：`open(..., "w")` 默认用系统编码（Windows 是 GBK），强烈建议加 `encoding="utf-8"`
4. **f-string 里写中文冒号**：`f"{x：2f}"` 里的 `：` 是中文冒号会报 `SyntaxError`
5. **`print` 默认换行**：想在一行内连续输出，用 `print(..., end="")`
