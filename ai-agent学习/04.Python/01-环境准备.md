## 本章目标

读完本章后，你将能够：

1. 在 Windows / macOS / Linux 上安装 Python 3.10+
2. 选择一个适合自己的编辑器（VS Code 为主推）
3. 用 REPL 交互式界面即时实验代码
4. 写出并运行你的第一个 Python 脚本 `hello.py`
5. 理解注释和基本的代码执行方式

> 📖 **Python**：一门解释型、动态类型的编程语言——你可以把它想象成一台"听得懂人类语言的指令机"：你写一行它立刻执行一行，不需要像 C/Java 那样先"编译"成二进制再运行。

## 1.1 安装 Python

### Windows（本教程的主要目标环境）

1. 访问官网 https://www.python.org/downloads/ 下载最新版（写本文时是 3.12.x）
2. 运行安装包时 **务必勾选 "Add Python to PATH"**（初学者最常漏的一步）
3. 选 "Install Now"，等 1 分钟完成
4. 验证：打开 PowerShell（或 CMD），输入：

```powershell
$ python --version
Python 3.12.x
```

> ⚠️ **踩坑**：如果报"python 不是内部命令"，大概率就是第 2 步没勾 PATH——解决方法：卸载重装或手动添加环境变量。

### macOS

macOS 自带的是 Python 2（已过时）。用 Homebrew 装 Python 3：

```bash
$ brew install python
$ python3 --version
Python 3.12.x
```

### Linux（Ubuntu / Debian）

```bash
$ sudo apt update
$ sudo apt install python3 python3-pip python3-venv
$ python3 --version
```

## 1.2 编辑器：从 VS Code 开始

> 📖 **编辑器**：写代码的"笔记本"。你可以用记事本写，但专用编辑器有高亮、补全、调试等"外挂"。

**推荐**：**VS Code**（免费、跨平台、生态强）。安装步骤：

1. 下载 https://code.visualstudio.com/ 并安装
2. 打开扩展市场（Ctrl+Shift+X），搜索并安装 **Python**（微软官方出品）
3. 新建一个文件夹 `python-tutorial/`，用 VS Code 打开，作为"工作区"
4. 在 VS Code 右下角确认选中 Python 解释器（命令面板 `Ctrl+Shift+P` → `Python: Select Interpreter`）

**备选**：

- **PyCharm Community**：免费、功能更全，但启动较慢
- **Jupyter Notebook**：适合数据科学场景，后面学 pandas 时会用到
- **Thonny**：初学者专用，界面极简

> 💡 **经验**：VS Code 是目前最主流的选择，生态丰富，后期写 AI Agent 代码也能用。

## 1.3 REPL：即时实验 Python

> 📖 **REPL**（Read-Eval-Print Loop）：交互式解释器——你输入一行代码，它立即执行并打印结果，像"计算器"一样随时验证你的想法。

在终端里输入 `python`（或 `python3`）进入：

```python
>>> 1 + 1
2
>>> "hello" * 3
'hellohellohello'
>>> import this
The Zen of Python, by Tim Peters

Beautiful is better than ugly.
...
```

- `this` 是 Python 自带的"哲学诗歌"，运行一次能看到 19 条设计哲学
- 退出 REPL：输入 `exit()` 或按 `Ctrl+D`（Unix）/ `Ctrl+Z` 后回车（Windows）

> 💡 **经验**：每次学到一个新特性，先在 REPL 里敲几行验证，比写完整文件快 10 倍。

## 1.4 写第一个脚本：hello.py

新建文件 `hello.py`，写入：

```python
# hello.py —— 我的第一个 Python 程序
print("Hello, World!")
print("你好，世界！")
```

在终端运行：

```powershell
$ python hello.py
Hello, World!
你好，世界！
```

**逐行讲解**：

- 第 1 行以 `#` 开头，是**注释**——Python 不会执行，只给人看
- `print()` 是内置**函数**，把括号里的内容打印到屏幕
- 字符串用**双引号** `""` 或**单引号** `''` 包起来（两者等价）

### 1.4.1 注释：代码里的"便签"

```python
# 单行注释：整行不会被执行

x = 10  # 行尾注释：跟在代码后面也可以

"""
这是多行注释（实际上是三引号字符串）
可以写很多行
常用于给函数写说明文档（docstring）
"""
```

> 📖 **Docstring**：紧跟在函数/类定义后面的三引号字符串——不是注释，是"活的说明文档"，能用 `help(函数名)` 调用，后面学函数时会细讲。

## 1.5 代码是怎么运行的

当你输入 `python hello.py` 时，背后发生了什么？

```
hello.py (源代码文本)
    ↓
Python 解释器读取源码
    ↓
逐行翻译成字节码 (.pyc)
    ↓
Python 虚拟机 (PVM) 逐行执行字节码
    ↓
输出结果 / 副作用（如写文件、发网络请求）
```

📖 **解释型语言**：代码在运行时逐行翻译执行，不像 C/Java 需要先全部编译成机器码。优点是开发快、改起来方便；缺点是比编译型语言慢一些。

## 1.6 第一个完整小例子

把下面代码保存为 `greet.py`：

```python
# greet.py —— 让用户输入名字，然后打招呼

name = input("你叫什么名字？")
print(f"你好，{name}！欢迎来到 Python 的世界！")
print("接下来请阅读第 2 章：变量与数据类型。")
```

运行：

```powershell
$ python greet.py
你叫什么名字？小明
你好，小明！欢迎来到 Python 的世界！
接下来请阅读第 2 章：变量与数据类型。
```

这段代码用到了下一章要学的所有要素：

- `name` 是一个**变量**
- `input()` 获取用户输入
- `f"..."` 是**格式化字符串**，把变量塞进文本里

看不懂没关系，下一章会讲清楚。

## ⚠️ 本章踩坑提醒

1. **PATH 没加**：安装时没勾 "Add Python to PATH" → 重装或手动加环境变量
2. **文件名带空格/中文**：`my test.py` 或 `测试.py` 在某些环境会出错——文件名用英文加下划线（如 `my_test.py`）
3. **把 `print` 写成 `println` / `printf`**：Python 只有 `print`，没有 `println`
4. **中文标点**：`print（"hello"）` 里的括号是中文全角，会报 `SyntaxError`
5. **编码问题**：Windows 终端默认 GBK，输出中文偶尔乱码——推荐用 PowerShell 或 VS Code 内置终端（默认 UTF-8）
