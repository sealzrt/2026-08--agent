## 9.1 读写文本文件

### 9.1.1 用 `with` 打开（推荐）

```python
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("你好，世界！\n")
    f.write("第二行\n")

with open("hello.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
```

📖 **`with` 语句**：自动管理"上下文"——离开 `with` 块时自动关闭文件，哪怕中间抛异常也不会泄漏文件句柄。**永远用 `with`，不要用裸 `open()`**。

### 9.1.2 模式参数

| 模式 | 含义 |
| --- | --- |
| `"r"` | 只读（默认） |
| `"w"` | 写入（覆盖原内容） |
| `"a"` | 追加 |
| `"x"` | 排他创建（文件已存在报错） |
| `"b"` | 二进制模式 |
| `"t"` | 文本模式（默认） |
| `"r+"` | 读写（文件必须存在） |

可组合：`"rb"` = 只读二进制，`"wb"` = 写二进制。

### 9.1.3 读文件的三种姿势

```python
# 1. 一次全读（文件小）
with open("x.txt", encoding="utf-8") as f:
    text = f.read()

# 2. 按行列表（文件小）
with open("x.txt", encoding="utf-8") as f:
    lines = f.readlines()      # 返回列表，每行带 \n

# 3. 迭代读（文件大，推荐）
with open("x.txt", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip())   # 去行尾换行
```

💡 **经验**：文件超过几十 MB，**不要用 `read()` 或 `readlines()`**，内存吃不消。用迭代读，一次只在内存里留一行。

## 9.2 处理 CSV

### 9.2.1 内置 `csv` 模块

```python
import csv

# 写 CSV
with open("data.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "年龄", "城市"])
    writer.writerow(["小明", 25, "北京"])
    writer.writerow(["小红", 23, "上海"])

# 读 CSV
with open("data.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    header = next(reader)
    for row in reader:
        print(row)
# ['小明', '25', '北京']
# ['小红', '23', '上海']
```

⚠️ `newline=""` 必须加，否则 Windows 下会多一个空行。

### 9.2.2 `DictReader`：按字段名访问

```python
with open("data.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["姓名"], row["年龄"])
```

### 9.2.3 `pandas`（进阶，第 13 章详讲）

```python
import pandas as pd
```

## 9.3 处理 JSON

```python
import json

person = {"name": "小明", "age": 25, "hobbies": ["读书", "游泳"]}

# 序列化：对象 → JSON 字符串
s = json.dumps(person, ensure_ascii=False, indent=2)

# 写入文件
with open("person.json", "w", encoding="utf-8") as f:
    json.dump(person, f, ensure_ascii=False, indent=2)

# 读取文件
with open("person.json", "r", encoding="utf-8") as f:
    data = json.load(f)

print(data["name"])        # 小明
```

> ⚠️ **`ensure_ascii=False`**：必须加，否则中文会变成 `\uXXXX` 转义。

## 9.4 路径处理：`pathlib`（现代写法）

> 📖 **`pathlib`**：Python 3.4+ 的路径处理库，用面向对象方式代替老式的 `os.path` 字符串拼接。

```python
from pathlib import Path

p = Path("data") / "2026" / "report.txt"   # 用 / 拼接
p.parent                                     # data/2026
p.name                                       # report.txt
p.stem                                       # report
p.suffix                                     # .txt
p.exists()                                   # 是否存在
p.is_file()                                  # 是否是文件
p.is_dir()                                   # 是否是目录
```

### 9.4.1 常用操作

```python
cwd = Path.cwd()                       # 当前工作目录
home = Path.home()                     # 用户主目录

# 创建目录
Path("new_folder").mkdir(parents=True, exist_ok=True)

# 列出目录
for p in Path(".").iterdir():
    print(p)

# 用 glob 模式搜索
for p in Path(".").glob("**/*.py"):    # 递归找所有 .py
    print(p)

# 读写文本（超简洁）
Path("note.txt").write_text("你好", encoding="utf-8")
text = Path("note.txt").read_text(encoding="utf-8")
```

💡 **经验**：新项目一律用 `pathlib`，别再用 `os.path.join` 拼路径了。

## 9.5 二进制文件

```python
# 复制文件
with open("src.png", "rb") as r, open("dst.png", "wb") as w:
    w.write(r.read())
```

`rb` / `wb` 处理的是 `bytes`，不会做编码转换——适合图片、音频、PDF 等。

## 9.6 临时文件与序列化

### 9.6.1 `tempfile`：系统级临时文件

```python
import tempfile

with tempfile.NamedTemporaryFile(mode="w", encoding="utf-8", delete=False) as f:
    f.write("临时数据")
    print(f.name)          # 系统生成的路径
```

### 9.6.2 `pickle`：Python 对象序列化

```python
import pickle

data = {"a": 1, "b": [1, 2, 3]}
with open("data.pkl", "wb") as f:
    pickle.dump(data, f)

with open("data.pkl", "rb") as f:
    loaded = pickle.load(f)
```

⚠️ **pickle 不安全**：永远不要 `pickle.load()` 来源不明的文件，它会执行任意代码。跨语言交换用 JSON。

## ⚠️ 本章踩坑提醒

1. **忘写 `encoding="utf-8"`**：Windows 默认 GBK，中文容易乱码
2. **`"w"` 模式会覆盖**：写之前确认是否要追加（`"a"`）
3. **CSV 不加 `newline=""`**：Windows 下每行会多一个空行
4. **JSON 忘写 `ensure_ascii=False`**：中文变 `\uXXXX`
5. **`with` 块外访问文件对象**：文件已关闭，访问会报错
6. **路径用 `\`**：Windows 下 `"C:\new\test"` 的 `\n` 会被当成换行——用 `r"C:\new\test"` 或 `Path`
