## 本章目标

读完本章后，你将能够：

1. 理解"变量"是什么，会起名字
2. 掌握 Python 的 5 种基础类型：整数、浮点数、字符串、布尔、None
3. 用 `type()` 查看类型，用 `int()`/`str()` 等做类型转换
4. 知道 Python 的"动态类型"和"强类型"是什么意思

> 📖 **变量**：一个带名字的盒子，里面装数据。就像快递盒子——盒子上贴标签（变量名），盒子里装东西（值），你随时可以把东西换掉，也可以把盒子交给别人用。

---

## 2.1 第一个变量

打开 REPL，跟着敲：

```python
>>> name = "小明"
>>> age = 25
>>> print(name, "今年", age, "岁")
小明 今年 25 岁
```

**发生了什么**：

- `name = "小明"`：创建一个字符串对象 `"小明"`，给它贴标签 `name`
- `age = 25`：创建一个整数对象 `25`，给它贴标签 `age`
- 变量名可以重新指向新对象：`age = 26` 后 `age` 就指向 26

> 📖 **赋值**（`=`）：不是"等于"，而是"把右边的值放进左边的盒子里"。"等于"在 Python 里是 `==`。

### 2.1.1 变量命名规则

| 规则 | 合法示例 | 不合法示例 |
| --- | --- | --- |
| 只能含字母、数字、下划线，**数字不能开头** | `my_name`、`x2` | `2x`、`my-name`（连字符是减号） |
| 不能用保留字 | `count` | `class`、`if`、`for` |
| 区分大小写 | `Name` 和 `name` 是两个变量 | |
| 推荐 snake_case（全小写+下划线） | `user_age`、`order_list` | `userAge`（驼峰，Python 不流行） |

💡 **经验**：变量名要有意义——`n = 3` 不如 `retry_count = 3`，半年后你还能看懂自己的代码。

## 2.2 五种基础类型

### 2.2.1 数字：整数 int 和 浮点数 float

```python
>>> x = 10          # 整数 int
>>> y = 3.14        # 浮点数 float
>>> z = 1_000_000   # 数字之间可以加下划线当千位分隔符，读起来方便
>>> type(x)
<class 'int'>
>>> type(y)
<class 'float'>
```

📖 **整数 int**：没有小数点的数，Python 的整数没有上限（不像 Java 的 int 最大 21 亿），所以可以算天文数字。

📖 **浮点数 float**：带小数点的数，但注意精度问题：

```python
>>> 0.1 + 0.2
0.30000000000000004   # 不是 0.3！
```

这不是 Python 的 bug，是所有二进制浮点数的通病。要精确小数，用 `decimal` 模块（金融场景必备，后面会提）。

### 2.2.2 字符串 str

```python
>>> s1 = "hello"
>>> s2 = 'world'         # 单引号和双引号等价
>>> s3 = """多行
... 字符串
... 可以跨行"""           # 三引号：跨行、保留换行
>>> s4 = "He said \"OK\"" # 转义字符：\" 表示一个引号本身
>>> type(s1)
<class 'str'>
```

字符串**不可变**（immutable）——后面会反复强调：所有"修改字符串"的操作，实际上都生成了新字符串。

### 2.2.3 布尔值 bool

```python
>>> is_valid = True
>>> is_empty = False
>>> type(True)
<class 'bool'>
```

📖 **布尔**：只有两个值 `True` 和 `False`（**首字母大写！**），用来表达"是/否""开/关"。

```python
>>> bool(0)
False
>>> bool("")
False
>>> bool(" ")         # 注意：一个空格不是空
True
>>> bool(42)
True
```

📖 **真值测试**（truthiness）：Python 允许把任意对象当成布尔用——空、零、None、空容器都被视为 False；其他都是 True。这是个很 Pythonic 的写法，后面写 `if` 时会反复用。

### 2.2.4 空值 NoneType

```python
>>> x = None
>>> type(x)
<class 'NoneType'>
>>> x == None
True
```

📖 **None**：表示"没有值"。和 `0`、`""`、`False` 都不一样——它是"这个位置还没填"，不是"填了 0"。

💡 **经验**：判断是否为 None 用 `is` 而不是 `==`：

```python
if result is None:   # 推荐
if result == None:   # 能跑，但不规范
```

## 2.3 查看类型与转换类型

### 2.3.1 `type()` —— 问"你是什么类型"

```python
>>> type(42)
<class 'int'>
>>> type("hello")
<class 'str'>
>>> type([1, 2, 3])
<class 'list'>
```

### 2.3.2 `int()` / `float()` / `str()` / `bool()` —— 类型转换

```python
>>> int("42")           # 字符串转整数
42
>>> float("3.14")       # 字符串转浮点
3.14
>>> str(100)            # 整数转字符串
'100'
>>> bool(0)
False
>>> int("hello")        # 不能转的会报错
Traceback ... ValueError
```

### 2.3.3 隐式转换

```python
>>> 3 + 4.5
7.5              # int + float 自动转成 float
>>> True + 1
2                # bool 是 int 的子类，True=1，False=0
```

> ⚠️ **踩坑**：`"3" + 4` 会报 `TypeError`——Python 是**强类型**，不会像 JS 那样自动把数字转成字符串拼接。必须显式转：`"3" + str(4)` 或 `int("3") + 4`。

## 2.4 动态类型

Python 是**动态类型**语言：同一个变量名可以先后指向不同类型的对象。

```python
>>> x = 10
>>> type(x)
<class 'int'>
>>> x = "hello"
>>> type(x)
<class 'str'>
```

这在 C/Java 里是不允许的（必须声明 `int x = 10;`）。灵活但有代价——变量类型只能靠你自己心里有数，或者靠类型注解（第 12 章会讲）。

## 2.5 变量赋值的高级玩法

### 2.5.1 多重赋值

```python
a, b, c = 1, 2, 3
a = b = c = 0            # 三个变量同时指向 0
```

### 2.5.2 交换变量（Python 独有的简洁写法）

```python
a, b = 1, 2
a, b = b, a              # 一行搞定交换
print(a, b)              # 2 1
```

C/Java 里你需要一个临时变量 `tmp`，Python 不需要。

### 2.5.3 增量赋值

```python
x = 10
x += 5      # x = x + 5
x *= 2      # x = x * 2
x //= 3     # x = x // 3  （整除）
```

## ⚠️ 本章踩坑提醒

1. **大小写**：`True` 不是 `true`，`None` 不是 `none`——Python 对大小写敏感
2. **`=` 不是 `==`**：赋值用 `=`，比较用 `==`，写反了是初学者最常见 bug
3. **浮点精度**：`0.1 + 0.2 != 0.3`，金融计算用 `decimal.Decimal`
4. **字符串拼接数字**：`"age: " + 25` 报错，必须 `str(25)` 或用 f-string（第 4 章）
5. **变量名遮蔽内置函数**：别把变量叫 `list`、`dict`、`print`——会把同名内置函数盖掉
