## 2.1 符号主义与早期智能体

### 一个大胆的假说

1956 年，纽厄尔和西蒙提出了**物理符号系统假说（PSSH）**：

> "任何表现出通用智能的系统，都必然是一个物理符号系统。"

翻译成人话：**思考就是操作符号**。如果一台机器能操作符号（比如把"A+B=C"中的 A 替换为 2，B 替换为 3，得出 5），那它就能思考。

这个假说催生了早期 AI 的两个重要方向：

### 专家系统：把专家的知识编码成规则

**类比**：把一位老医生的诊断经验，变成一本"如果...那么..."的手册。

```
如果 患者体温 > 38.5 且 咳嗽持续 > 7 天
那么 可能诊断：肺炎
     建议：胸部X光检查
```

专家系统由两部分组成：
- **知识库**：大量 if-then 规则（"如果...那么..."）
- **推理机**：根据输入事实，匹配规则，得出结论

它在 1980 年代非常成功（如 MYCIN 医疗诊断系统），但最终被三个致命问题打败：
1. **知识获取瓶颈**：需要人类专家一条条写规则，费时费力
2. **脆弱性**：遇到规则没覆盖的情况就"傻了"
3. **无法学习**：不能从新经验中自动改进

### SHRDLU：第一个"能做事"的智能体

1970 年，MIT 的 Terry Winograd 创造了 SHRDLU——一个能理解自然语言并**操控虚拟积木**的系统。

你可以对它说："把红色的方块放到绿色积木上面"，它就会执行动作。

SHRDLU 的重要性在于：它是第一个展示了"语言理解 + 物理行动"结合的系统——这正是现代智能体的核心特征。

> 💡 **历史回音**：SHRDLU 的"理解语言→执行动作"模式，就是今天智能体"工具调用"的思想原型（详见 Ch4）。

## 2.2 从 ELIZA 到心智社会

### ELIZA：第一个聊天机器人

1966 年，MIT 的 Joseph Weizenbaum 创造了 ELIZA，它模拟一位心理治疗师，通过**模式匹配**来回复用户。

ELIZA 的核心逻辑非常简单：

```python
# ELIZA 的核心规则：正则模式 → 回复模板
# 每条规则包含：正则表达式（用于匹配用户输入）+ 回复模板列表（随机选一个）
rules = {
    r"I am (.*)":        ["How long have you been {0}?", "Why do you say you are {0}?"],
    r"I feel (.*)":      ["Tell me more about feeling {0}.", "How often do you feel {0}?"],
    r"(.*) sorry (.*)":  ["What are you sorry about?", "Why are you apologizing?"],
    r"(.*)":             ["Tell me more.", "Can you elaborate?", "I see."]  # 默认兜底规则
}
```

它的工作原理：
1. 用户输入一句话
2. 按顺序匹配规则，找到第一个匹配的模式
3. 用匹配到的模板生成回复（代词转换："I" → "you"）

### 动手运行 ELIZA

```python
import re, random                        # re 用于正则匹配，random 用于随机选回复

# --- 规则定义：正则模式 → 回复模板列表 ---
rules = {
    r"I am (.*)":        ["How long have you been {0}?", "Why do you say you are {0}?"],
    r"I feel (.*)":      ["Tell me more about feeling {0}."],
    r"(.*) sorry (.*)":  ["What are you sorry about?"],
    r"(.*)":             ["Tell me more.", "Can you elaborate?", "I see."]  # 兜底
}

# --- 代词转换表：将“我”转为“你”，实现视角切换 ---
pronouns = {"I": "you", "my": "your", "me": "you", "am": "are"}

def swap(text):
    """将用户输入中的第一人称代词转为第二人称（如 "I am sad" → "you are sad"）"""
    words = text.split()
    return " ".join(pronouns.get(w, w) for w in words)  # 查表转换，找不到则保留原词

def respond(user_input):
    """根据规则匹配用户输入，生成回复"""
    for pattern, responses in rules.items():     # 按顺序遍历规则
        match = re.match(pattern, user_input, re.I)  # 尝试匹配（不区分大小写）
        if match:                                # 匹配成功
            template = random.choice(responses)  # 随机选一个回复模板
            groups = [swap(g) for g in match.groups()]  # 提取捕获组并做代词转换
            return template.format(*groups) if groups else template  # 填充模板
    return "I'm not sure I understand."          # 全部规则都不匹配时的兜底回复

# --- 对话循环：模拟与 ELIZA 的交互 ---
print("ELIZA: Hello! How are you feeling today?")
while True:
    user = input("You: ")                        # 获取用户输入
    if user.lower() in ("quit", "exit"):         # 输入 quit 退出
        break
    print(f"ELIZA: {respond(user)}")             # 生成并打印回复
```

运行这段代码，和 ELIZA 对话几轮。你会发现：
- 它看起来很"聪明"（"你很难过？告诉我更多"）
- 但多聊几轮就露馅了（它并不真正理解你说的话）

### 模式匹配的局限

| 局限 | 示例 |
|------|------|
| 只能回复预设模式 | 用户说"我飞到了月球"→ ELIZA 只会说"告诉我更多" |
| 没有记忆 | 不记得你 3 分钟前说过什么 |
| 没有理解 | "I am happy" 和 "I am sad" 触发同一条规则 |

> 💡 **历史回音**：ELIZA 的失败证明了一件事——**规则无法覆盖语言的无限组合**。这正是 60 年后 LLM 解决的核心问题。

### 马文·明斯基的心智社会

1986 年，MIT 的马文·明斯基出版了《心智社会》一书，提出了一个颠覆性的观点：

> **智能不是来自一个"超级大脑"，而是来自大量简单"智能体"的协作。**

他认为，人的思维由成百上千个"微智能体"组成：
- 一个负责识别形状
- 一个负责理解颜色
- 一个负责规划动作
- ...

这些微智能体各自简单，但协作起来就产生了"智能"。

> 💡 **历史回音**：心智社会理论是**多智能体系统**的思想源头。第 12 章中，我们将把多个 Agent 组织成一个团队，让它们分工协作完成复杂任务。

## 2.3 学习范式演进与现代智能体

### 从规则到学习

早期 AI（符号主义）的核心问题是：**规则由人编写，无法自动学习。** 这导致了三次范式跃迁：

```
第一次跃迁：符号 → 联结（1980s-1990s）
   从"人写规则"到"机器从数据中学习规则"
   代表：神经网络、反向传播

第二次跃迁：监督学习 → 强化学习（1990s-2010s）
   从"给标准答案"到"给奖励信号"
   代表：AlphaGo、Deep Q-Network

第三次跃迁：专项学习 → 大规模预训练（2017-now）
   从"一个模型做一件事"到"一个模型学会语言能力，再适配各任务"
   代表：Transformer、GPT、ChatGPT
```

### 每一次跃迁解决了什么？

| 范式 | 优势 | 仍然的问题 |
|------|------|-----------|
| 符号主义 | 可解释、逻辑严谨 | 知识获取瓶颈、无法处理模糊信息 |
| 联结主义 | 能从数据中学习 | 需要大量标注数据 |
| 强化学习 | 能在试错中学习 | 训练不稳定、样本效率低 |
| 预训练大模型 | 通用语言能力、少样本学习 | 幻觉、缺乏实时信息 |

### 现代智能体：集大成者

现代 LLM 智能体并不是凭空出现的，它是上述所有范式的**集大成者**：

| 现代智能体的能力 | 历史来源 |
|----------------|---------|
| 自然语言理解 | 预训练大模型（第三次跃迁） |
| 工具调用与行动 | SHRDLU 的"语言→行动"模式 |
| 多步推理与规划 | 符号主义的逻辑推理 |
| 从反馈中学习 | 强化学习的奖励机制 |
| 多智能体协作 | 心智社会的分工协作思想 |

## 2.4 历史启示录：对当代 Agent 设计的启发

从历史中，我们可以提炼出 4 条至今仍有效的设计原则：

### 原则 1：智能体需要"手脚"（来自 SHRDLU）

只会说话的 AI 是有局限的。SHRDLU 的价值在于证明：语言理解必须与行动能力结合。**这就是为什么第 4 章要讲工具调用。**

### 原则 2：规则无法覆盖所有情况（来自 ELIZA 和专家系统）

ELIZA 和专家系统的失败证明了同一件事：手写规则不可能覆盖语言的无限组合。**这就是为什么我们需要 LLM 作为智能体的"大脑"。**

### 原则 3：协作比单体更强（来自心智社会）

一个超级智能体不如一群分工明确的简单智能体。**这就是为什么第 12 章要讲多智能体系统。**

### 原则 4：学习比编程更高效（来自范式演进史）

与其花时间写规则，不如让系统从数据中学习。**这就是为什么第 14 章要讲用强化学习训练智能体。**

### 🚧 常见坑

**坑 #1：模式匹配的顺序敏感**
- 现象：ELIZA 总是回复同一句话
- 原因：规则按顺序匹配，通配规则 `(.*)` 可能提前截获了其他规则的输入
- 解决：把通配规则放在最后
