  - D1 工具定位：本体建模 + 业务风险管控 **两者并重**

- 技术栈：Vue3 + TS + Vite + Pinia + Element Plus + AntV G6；参考开源：Protégé、Owlready2、kg_mem、HugAgentOS、Graphiti。
- 里程碑 M1-M5：骨架 → 本体建模 → 业务模块+导入 → 规则引擎+风险中心 → 仪表盘+图谱+LLM。

- v0.3 新增模块：售前管理(Bid)、运维管理(OpsEvent/SLA/质保期)、文档中心、自动识别流水线(要素抽取→规则匹配→关系推演→人工确认)。
