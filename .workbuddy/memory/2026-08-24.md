## 配图格式调整：SVG → PNG（VSCode 兼容）

- 用户反馈：VSCode 内置 Markdown 预览看不到内联 SVG 图表——原因是 `markdown.preview.allowUnsafeHtml` 默认 false，HTML/SVG 标签会被剥离（不是插件问题）
- 决定改用 PNG 图片（任何环境零配置可见）
- 渲染工作流：md 中提取 svg → 生成白底 HTML 包装页 → 本地起 python http.server → Chrome headless 截图（2x 高清，680xH 视口）→ 脚本把 svg 替换为 `![alt](assets/figN-xxx.png)` 引用
- 重要坑：Chrome headless 在 Windows 下访问 `file:///` 协议会 ERR_FILE_NOT_FOUND，必须用 http URL（起一个本地 http.server 即可）
- 最终产物（已落地）：
  - 教程文档 `01-概念基础/01.为什么需要本体论.md`
  - 图片目录 `01-概念基础/assets/` 含 4 张 PNG
  - 图一 fig1-who-understands.png、图二 fig2-fragmentation.png、图三 fig3-code-forgotten.png、图四 fig4-blackhole.png
