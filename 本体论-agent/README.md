# 本体论 + Agent（10 章白话版）

这是"本体论 + Agent"学习教程的工作目录。**全部章节已重写为白话讲解**：开场先讲一个扎心问题，中间用类比和真实业务例子讲透，最后动手试试。

## 快速入门（推荐先读）

1. 先读主文档的 **第 0 章「一页纸讲清楚本体论」**：本体论是什么、和知识图谱/RAG/记忆/Agent 的区别、价值分四个层次、落地心法
2. 按章节顺序读 10 章（每章 20-30 分钟）

> 不需要任何 RDF/OWL 前置知识。术语出现的地方都配了"说白了"。

## 学习主线（10 章）

```
01 为什么需要本体论      → AI 最缺的不是聪明，是"懂业务"
02 本体论到底是个啥      → 业务世界的概念地图 + 游戏规则
03 本体在AI系统里站在哪  → 本体是所有零件共守的"业务说明书"
04 怎么从业务里抽出本体  → 先想业务判断，圈最小范围，最后才接 AI
05 把数据装进知识图谱    → 把原始记录翻译成带标签的"事实"
06 怎么查、怎么推        → 查=模板捞数据，推=规则算新事实
07 让AI记住、搜得准      → AI 的记性靠本体补（记忆 + 增强 RAG）
08 让AI会规划挑工具走流程 → AI=新员工，本体=岗位说明书+流程图
09 管住AI：权限、安全、人工审核 → 门禁卡 + 高风险领导签字（HITL）
10 完整项目：从合同到风险闭环 → 9 章串成一条能自己跑通的业务链
```
